# Ibrahim Awwab

**Medical Microbiologist · Cybersecurity Specialist · Independent Researcher · Author**

Ibrahim Awwab is a medical microbiologist, cybersecurity specialist, independent researcher, educator and author. His professional interests include clinical microbiology, infectious diseases, antimicrobial resistance, molecular diagnostics, healthcare cybersecurity, digital forensics and information security.

His work brings together scientific communication, responsible technology and evidence-based research. Through educational initiatives, technical projects and public writing, he explores how scientific knowledge and digital security can contribute to safer healthcare systems and more accessible learning.

He is the author of *The Legacy of Wisdom*.

Official professional portfolio: https://ibrahimawwab.github.io/

## Areas of focus

- **Medical microbiology:** diagnostic microbiology, laboratory practice, and scientific interpretation.
- **Cybersecurity:** defensive security, security awareness, and secure system design.
- **Digital forensics:** digital evidence concepts, investigation methods, and analytical workflows.
- **AI and automation:** privacy-conscious assistants, workflow automation, and practical software tools.
- **Open-source engineering:** maintainable code, documented decisions, testing, and responsible collaboration.

## Featured project

### [RealityCheck](https://github.com/ibrahimawwab/RealityCheck)

An evidence-verification platform in development, intended to help investigate factual claims, evaluate source credibility, preserve provenance, and produce transparent, reproducible assessments. A public release is contingent on security review and explicit approval.

**Current status: Pre-alpha.** The repository contains an initial Python API and domain foundation, controlled evidence-ingestion components, documentation, tests, and CI. It is not production-ready. See the project README and roadmap for implemented capabilities and outstanding work.
